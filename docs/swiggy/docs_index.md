## Built on the standard

Swiggy Builders Club speaks [Model Context Protocol](https://modelcontextprotocol.io) over streamable HTTP. Any MCP-compatible client or framework works out of the box - no bespoke SDK, no lock-in. Authentication is OAuth 2.1 with PKCE.
